# Documentation

The documentation is divided by purpose:

- [Main README](../README.md) — installation, normal usage, configuration, and common troubleshooting.
- [Architecture](architecture.md) — how the application is organized and how to safely extend it.
- [Lumo Stories](lumo.md) — how the Lumo scraper discovers and extracts chapters and how to diagnose failures.
- [Cleaning](cleaning.md) — how downloaded chapter files are cleaned before ebook compilation.
- [Troubleshooting](troubleshooting.md) — practical diagnosis of installation, scraping, EPUB, and PDF problems.

If you are a normal user, start with the main README.

If you are maintaining or extending the project, read `architecture.md` first.
